# АэроСправочник — стартовая версия

## Что уже работает
- адаптивная главная страница;
- поиск по названию, типу и назначению;
- фильтр по категориям;
- открывающиеся статьи с назначением, общим принципом работы и справочными особенностями;
- базовая доступность с клавиатуры;
- без сборки, платных сервисов или базы данных.

## Как открыть на компьютере
Самый простой способ: распакуйте архив и откройте `index.html` в современном браузере.
Для обычного просмотра всё работает как статический сайт.

## Как опубликовать бесплатно через GitHub Pages
1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Создайте новый публичный репозиторий, например `aerospravochnik`.
3. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `script.js` и `README.md`.
4. Откройте в репозитории **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**.
6. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
7. Подождите завершения публикации. GitHub покажет адрес сайта на странице Pages.

## Перед публичным запуском
- Проверьте каждую статью и добавьте ссылки на надёжные первичные источники.
- Укажите дату последней проверки характеристик конкретных моделей.
- Используйте изображения только с разрешённой лицензией и указывайте авторство.
- Добавьте контакт редакции и политику конфиденциальности, если позже появятся формы, аналитика или сбор данных.
- Материалы о военных системах сейчас обзорные и не являются руководством по применению.

## Структура
- `index.html` — содержание и структура страниц.
- `styles.css` — внешний вид.
- `script.js` — каталог, поиск, фильтры и содержимое статей.

## Как изменить статьи
Откройте `script.js` в текстовом редакторе и найдите массив `articles`. Каждый объект — одна статья. Можно редактировать поля `title`, `summary`, `purpose`, `principle`, `specs` и `note`.
