# АэроСправочник — Aero Premium 0.2

Обновлённый тёмный дизайн в строгом авиационном стиле: чертёжная сетка, бирюзовые акценты, адаптивный каталог, поиск, фильтры и всплывающие статьи.

## Файлы
- `index.html` — структура сайта и главная страница.
- `styles.css` — оформление и адаптация для смартфонов.
- `script.js` — каталог, поиск, фильтры и карточки статей.

## Как обновить существующий сайт через Android
1. Скачайте ZIP и распакуйте его в приложении «Файлы».
2. Откройте ваш репозиторий GitHub в браузере.
3. Нажмите **Add file → Upload files**.
4. Выберите из распакованной папки файлы `index.html`, `styles.css` и `script.js` (README можно тоже заменить, если хотите).
5. Нажмите **Commit changes** и подтвердите сохранение.
6. Подождите 1–5 минут, затем обновите сайт. Если видите старую версию, перезагрузите страницу или откройте её в новой вкладке.

Важно: выбирайте сами файлы, а не ZIP. Все три файла должны лежать рядом в корне репозитория, не во вложенной папке. Имена файлов должны совпадать точно.

Сайт не требует сборки, сервера или платных сервисов. Статьи в каталоге являются обзорными демонстрационными материалами; конкретные технические данные следует сверять с надёжными источниками.
